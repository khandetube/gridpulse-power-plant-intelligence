# Authorized historical data request

GridPulse AI is an independent portfolio research project. Public reporting alone is not enough to validate plant-level performance or train a reliable maintenance model.

## Optional data request
If the operator explicitly authorizes release, a small anonymized historical CSV/XLSX sample could include:
- Reporting period and timezone
- Approved plant/unit pseudonym
- Metric name, numeric value, and explicit unit
- Aggregation interval and data-quality flag
- Source owner and written permission for portfolio use
- For maintenance research: event date, equipment category, planned/unplanned classification, and downtime duration

## Safety and confidentiality
Do not provide credentials, API keys, VPN details, network diagrams, IP addresses, sensitive control-system tags, protection settings, dispatch credentials, control commands, or non-public security logs. Do not connect this project to operational technology. Keep original files outside the public repository unless publication is explicitly permitted.

## Review steps
1. Obtain written authorization and confirm the permitted publication scope.
2. Remove personal, security-sensitive, and commercially restricted fields.
3. Validate schema, dates, units, duplicate identifiers, and provenance.
4. Publish only approved sanitized data with coverage and limitations documented.
5. Never mark a source verified merely because its file passes schema validation.
