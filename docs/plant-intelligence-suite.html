Data lineage & quality controls

  • Each observation should include source ID, timestamp/period, unit, boundary and review status.
  • Keep raw data immutable; store transformations and analyst decisions separately.
  • Distinguish measured, calculated, estimated and synthetic values.
  • Record model version, input window, missing data, confidence and reviewer sign-off.
  • Restrict access by role; log changes and export actions.

Workspace portability

Export the locally stored registers to JSON for backup/review. This page stores data in this browser only. It does not transmit to a server.
