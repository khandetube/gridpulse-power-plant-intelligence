# GridPulse AI Engineering Engine

The AI layer is intentionally evidence-first. It reasons over the current model and explicit requirements, then emits traceable findings and actions. It does not invent equipment ratings, dimensions, process values, protection settings, code compliance, or manufacturer data.

## Pipeline

`Prompt -> requirement extraction -> topology/model -> deterministic calculations -> engineering reasoning -> quality gate -> coordinated export`

## Reasoning capabilities

- unresolved route endpoints
- duplicate asset identifiers
- missing multidisciplinary coverage
- incomplete asset coordinates
- incomplete geometry
- missing connectivity
- severity-ranked action queue
- deterministic confidence and evidence for every finding
- explicit limitations and review status

## Safety boundary

The engine is a design-screening and coordination assistant. Safety-critical and execution-grade designs require authoritative project data, applicable standards, qualified engineering review, and validated native CAD/BIM workflows.
