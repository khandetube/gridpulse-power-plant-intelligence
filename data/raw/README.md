# Raw data

Store only public source files or operational exports that you are authorized to use.

For each file, document its source URL or provider, retrieval date, license/permission, reporting period, units, aggregation scope, and checksum where practical.

Do not commit credentials, personal information, confidential plant records, SCADA exports, dispatch-center data, or other restricted operational information. If no source file is available, leave this directory empty rather than manufacturing data.
